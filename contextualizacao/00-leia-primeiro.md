## 1. O que é o AcadChain?
O AcadChain é um projeto científico e protótipo acadêmico para investigar a autenticação e validação de diplomas, certificados e carteirinhas estudantis digitais utilizando:
- **Hashing criptográfico (SHA-256)** para integridade documental.
- **SQLite local** (com módulo nativo `node:sqlite`) para armazenamento e gestão de dados relacionais.
- **Rede Blockchain Ethereum local** (planejada para a Etapa 2 via Hardhat 3) para registro imutável e descentralizado de provas de emissão.
- **Frontend moderno (React + Vite + Tailwind)** para interação intuitiva entre instituições, estudantes e verificadores externos.

---

## 2. Em qual etapa estamos?
- **Estamos na ETAPA 1:** Fundação da arquitetura, banco de dados relacional SQLite, backend Express em TypeScript, frontend React responsivo e scripts Windows 11.
- **O que NÃO fazer nesta etapa:** Não tentar conectar MetaMask, não subir nó Hardhat ainda, não inventar contratos inteligentes Solidity nem simular transações como se fossem reais.
